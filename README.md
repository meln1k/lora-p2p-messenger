# LoRa P2P Messenger

Standalone ESP32-S3 T-Beam firmware using Embassy, with LoRa messaging,
an SH1106 OLED display, button controls, power management, and a Wi-Fi web UI.

## Build and flash

Requires the Espressif Rust toolchain named `esp` and `espflash`.
The default target is `xtensa-esp32s3-none-elf`.
From the repository directory, load the environment script generated by espup,
then build and flash. These are the steps verified on the connected USB radio:

```sh
source "$HOME/export-esp.sh"
cargo run --release --locked -- --port /dev/cu.usbmodem1101
```

Replace `/dev/cu.usbmodem1101` with your device’s serial port. On macOS, use
`ls /dev/cu.*` to find serial ports. `$HOME` refers to your own home directory;
use the environment script generated by your local espup installation.

`cargo run` builds the firmware, flashes the ESP32-S3, and opens its serial
monitor. Press `Ctrl+C` to exit the monitor; the firmware keeps running.
`--locked` requires Cargo to use `Cargo.lock` without changing it.

To build without flashing:

```sh
cargo build --release --locked
```

## Host library tests

On Apple Silicon macOS:

```sh
cargo +stable test-host
```

On other hosts, specify your installed host target:

```sh
cargo +stable test --lib --target <host-triple>
```

The `test-host` alias is defined in `.cargo/config.toml`.
