# LoRa P2P Messenger

Standalone ESP32-S3 T-Beam firmware using Embassy, with LoRa messaging,
an SH1106 OLED display, button controls, power management, and a Wi-Fi web UI.

## Build and flash

Requires `espup`, `espflash`, and the Espressif Rust 1.97.0.0 toolchain.
The ESP dependencies require Rust 1.95 or newer. Install the toolchain under
the name selected by `rust-toolchain.toml`:

```sh
espup install --name esp-1.97 --toolchain-version 1.97.0.0 --targets esp32s3 --export-file "$HOME/export-esp-1.97.sh"
```

The default target is `xtensa-esp32s3-none-elf`. From the repository directory,
load the generated environment script, then build and flash:

```sh
source "$HOME/export-esp-1.97.sh"
cargo run --release --locked -- --port /dev/cu.usbmodem1101
```

Replace `/dev/cu.usbmodem1101` with your device’s serial port. On macOS, use
`ls /dev/cu.*` to find serial ports. `$HOME` refers to your own home directory;
use the environment script generated by your local espup installation.

`cargo run` builds the firmware, flashes the ESP32-S3, and opens its serial
monitor. Press `Ctrl+C` to exit the monitor; the firmware keeps running.
`--locked` requires Cargo to use `Cargo.lock` without changing it.

To build without flashing:

```sh
cargo build --release --locked
```

## Wi-Fi web UI capacity

The access point admits at most **4 Wi-Fi clients**, tracked in fixed-size storage.
The HTTP server has **4 concurrent connections** shared by all clients. Each
worker has its own statically allocated socket and buffers; a complete request
has a 15-second deadline so a slow connection cannot occupy a worker indefinitely.
When all workers are occupied, new connections may be rejected; there is no
additional accept queue. The event stream uses short responses and reconnects.
One shared task collects received radio messages for all web clients.

## Host library tests

On Apple Silicon macOS:

```sh
cargo +stable test-host --locked
```

On other hosts, specify your installed host target:

```sh
cargo +stable test --locked --lib --target <host-triple>
```

The `test-host` alias is defined in `.cargo/config.toml`.
